Este repo ya tiene index.html y manifest.webmanifest. Se añadió un service worker básico en service-worker.js para mejorar la experiencia PWA.

Para publicar en GitHub Pages:
1. Ve a Settings → Pages del repo.
2. En "Source" selecciona la rama "gh-pages" y / (root).
3. Guarda y espera unos minutos. La URL será:
   https://elenamartintrujillo-ux.github.io/mi-ppagina/

Si quieres que añada iconos PNG (icon-192.png, icon-512.png) o un PR en lugar de push directo, dímelo.
